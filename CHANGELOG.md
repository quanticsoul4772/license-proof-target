## [Unreleased]

### Added

- `README.md` describing the repository as a scratch contribution target for a
  license-class proof, with a pointer to `CONTRIBUTING.md`.
- `LICENSE` file containing the MIT License (copyright 2026 quanticsoul4772).
- `CONTRIBUTING.md` covering forking, topic branches, editing, commit message
  expectations, pull requests and licensing of contributions.
- `CODE_OF_CONDUCT.md` based on the Contributor Covenant.
- `SECURITY.md` with the supported-versions policy and instructions for
  reporting vulnerabilities through GitHub private vulnerability reporting.
- `.editorconfig` defining UTF-8, LF line endings, a final newline, 4-space
  indentation, 2-space indentation for `.github` YAML and preserved trailing
  spaces in Markdown.
- `.github` configuration: a `CODEOWNERS` file assigning `@quanticsoul4772` as
  default owner, a bug report issue template and a pull request template.
